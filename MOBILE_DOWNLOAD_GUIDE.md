# 📱 How to Download & Install Hive Property on Your Phone

## 🚀 Quick Start (3 Minutes)

### Step 1: Open GitHub on Your Phone
1. **Open your phone's browser** (Chrome, Edge, or Firefox)
2. **Navigate to:** `github.com/YOUR_USERNAME/lovly-prop-ai-33`
3. **Tap the "Releases" tab** (between "Code" and "Packages")

### Step 2: Download the APK
1. **Find the latest release** (at the top)
2. **Scroll down to "Assets"**
3. **Tap:** `HiveProperty-vX.X.X.apk`
4. **Wait for download** to complete

### Step 3: Install the App
1. **Open your Downloads folder**
2. **Tap the downloaded APK file**
3. **If prompted:** Enable "Install unknown apps"
   - Android 8+: Settings → Apps → Special Access → Install Unknown Apps → [Your Browser] → Allow
   - Android 10+: Settings → Apps → Special App Access → Install Unknown Apps → Files → Allow
4. **Tap "Install"**
5. **Tap "Open"** when done

### Step 4: Grant Permissions
When you first open the app, grant these permissions:
- ✅ **Notifications** - For rent reminders & alerts
- ✅ **Camera** - For uploading property photos
- ✅ **Storage** - For saving documents
- ✅ **Location** - For property maps (optional)

## 🔄 How Updates Work

### Automatic Build on Every Push
Every time code is pushed to the `main` branch:
1. ✅ GitHub Actions **automatically builds** a new APK
2. ✅ Creates a new **version tag** (v1.0.1, v1.0.2, etc.)
3. ✅ Uploads the APK to **Releases** tab
4. ✅ You get notified of the new release

### To Update Your App:
1. **Go to Releases tab** on your phone
2. **Download the latest version**
3. **Install** (it will update the existing app)
4. **Done!** ✨

## 🔧 Troubleshooting

### "There was a problem parsing the package"
- ✅ Make sure you downloaded the **complete file** (not a ZIP)
- ✅ Check your phone's **Android version** (needs 6.0+)
- ✅ Try **re-downloading** the APK
- ✅ Enable "Install unknown apps" for your browser

### "App not installed"
- ✅ **Uninstall** any old version first
- ✅ Check you have **enough storage** (need ~50MB free)
- ✅ Restart your phone and try again

### "For security, your phone is not allowed to install unknown apps"
- ✅ Go to: **Settings → Security → Unknown Sources** → Enable
- ✅ OR: **Settings → Apps → Special Access → Install Unknown Apps** → Enable for your browser

### APK won't download
- ✅ Check your **internet connection**
- ✅ Clear browser **cache & data**
- ✅ Try a different **browser**
- ✅ Free up **storage space** (need ~20MB)
